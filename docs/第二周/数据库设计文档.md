## 一、设计原则与约定

### 1.1 命名与字符集
- **库名**：`eopmis`（与 PROJECT.md 端口名一致）
- **表名、字段名**：小写加下划线（snake_case），以 `sys_` 前缀标识系统底座表（账号/权限/字典/审计）
- **字符集**：`utf8mb4`，**排序规则**：`utf8mb4_unicode_ci`
- **存储引擎**：`InnoDB`（支持事务、行锁、MVCC）
- **主键**：所有业务表均使用 `id BIGINT UNSIGNED AUTO_INCREMENT`，自然键额外加 UNIQUE 索引

### 1.2 通用字段
每张业务表均包含以下审计字段（除特殊说明外）：

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `create_time` | DATETIME | CURRENT_TIMESTAMP | 创建时间 |
| `update_time` | DATETIME | CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP | 更新时间 |
| `create_by` | BIGINT UNSIGNED | NULL | 创建人 user_id（可空） |
| `update_by` | BIGINT UNSIGNED | NULL | 更新人 user_id（可空） |

需要逻辑删除的表加 `del_flag TINYINT NOT NULL DEFAULT 0`（0 正常 / 1 已删）。
状态字段统一 `status TINYINT NOT NULL DEFAULT 1`（1 启用 / 0 停用），员工主表扩展为 `1 在职 / 2 离职`。

### 1.3 敏感字段加密
按概要设计 §1.2 评审结论：身份证号、手机号、家庭关系联系方式、薪资字段等敏感字段在写入前由后端 TypeHandler/AES 加密：

- **列类型**：`VARCHAR(255)` 存密文（base64），列 comment 注明"加密存储"
- **读出**：由后端解密，业务层返回明文
- **唯一性**：在密文上加 UNIQUE 索引，由后端传入密文校验
- **检索**：身份证号/手机号不直接做 LIKE 查询，必要时由后端在内存中解密后匹配

### 1.4 外键策略
按概要设计 Q10 评审结论：**使用逻辑外键 + 唯一索引 + 应用校验**，不建立物理外键约束。

### 1.5 索引策略
- 高频查询列：单列 B-Tree 索引
- 高频组合查询：联合索引（最左前缀原则）
- 唯一约束列：UNIQUE 索引
- 不在 `TEXT` 上建全文索引（本版不需要）
- 单表索引控制在 5 个以内，优先保证 WHERE / JOIN / ORDER BY 列

### 1.6 金额与时间
- **金额**：`DECIMAL(10,2)`，元为单位，保留 2 位
- **日期**：`DATE`（如入职日期、合同起止）
- **日期时间**：`DATETIME`（如登录时间、审批时间）
- **薪资月份**：`VARCHAR(7)`，格式 `yyyy-MM`（如 `2026-09`）

### 1.7 模块与表对照
按 M01~M10 拆分后共 **21 张表**：

| 模块 | 编号 | 表数 | 表名 |
|------|------|------|------|
| 认证权限 | M01 / M10 | 6 | `sys_user`、`sys_role`、`sys_permission`、`sys_role_permission`、`sys_password_history`、`sys_audit_log`、`sys_dict` |
| 组织 | M03 / M04 | 2 | `dept`、`position` |
| 员工档案 | M02 | 6 | `employee`、`employee_education`、`employee_work_experience`、`employee_family`、`employee_attachment`、`employee_view_log` |
| 劳动合同 | M05 | 1 | `contract` |
| 人事调动 | M06 | 1 | `job_transfer` |
| 薪资管理 | M07 | 2 | `salary_record`、`salary_change_log` |
| 考勤管理 | M08 | 1 | `attendance_record` |
| 请假审批 | M09 | 1 | `leave_application` |

## 三、数据字典

> 字段说明：M = NOT NULL；空 = NULL 允许；PK = 主键；UQ = 唯一索引；IDX = 普通索引

### 3.1 sys_user（用户账号）— M01

| 字段 | 类型 | 约束 | 默认 | 说明 |
|------|------|------|------|------|
| id | BIGINT UNSIGNED | PK, AUTO_INCREMENT | — | 主键 |
| username | VARCHAR(50) | M, UQ | — | 登录账号（唯一） |
| password | VARCHAR(100) | M | — | BCrypt 哈希（60 字符，保留长度） |
| real_name | VARCHAR(50) | M | — | 真实姓名 |
| role_id | BIGINT UNSIGNED | M, IDX | — | 逻辑外键 → sys_role.id（FR-001 一角色） |
| employee_id | BIGINT UNSIGNED | UQ, NULL | NULL | 普通职工必绑；逻辑外键 → employee.id |
| status | TINYINT | M | 1 | 1 启用 / 0 停用 |
| last_login_time | DATETIME | NULL | NULL | 最后登录时间 |
| last_login_ip | VARCHAR(50) | NULL | NULL | 最后登录 IP |
| failed_attempts | INT UNSIGNED | M | 0 | 连续登录失败次数，≥5 触发锁定 |
| locked_until | DATETIME | NULL | NULL | 锁定截止时间，15 分钟后自动解锁 |

## 七、部署与运行说明

### 7.1 执行步骤
1. MySQL 8.0+ 启动后，使用 root 账号登录
2. 执行 §四 SQL 一次性建库建表
3. 执行 §五 初始化数据
4. 后端 `application.yml` 配置 `spring.datasource.url=jdbc:mysql://localhost:3306/eopmis?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai`
5. 启动 SpringBoot，使用 admin/YOUR_ADMIN_PWD 登录

### 7.2 备份策略
- `mysqldump -uroot -p eopmis > eopmis_$(date +%F).sql` 每日全量
- 审计日志表按月分区或按月导出归档（详见运维文档）
