## 全局约定（接口公共规范）

### 1. 统一返回体

所有接口（除文件下载外）均返回 JSON：

| 字段 | 类型 | 说明 |
|------|------|------|
| code | Integer | 业务状态码，200 成功；4xx 客户端错误；5xx 服务端错误 |
| message | String | 提示信息，成功时为 "success"，失败时为可读提示 |
| data | Object | 业务数据，可为 null |

### 2. 分页返回体 data

| 字段 | 类型 | 说明 |
|------|------|------|
| records | Array | 当前页数据列表 |
| total | Long | 总记录数 |
| current | Integer | 当前页码，默认 1 |
| size | Integer | 每页条数，默认 20 |

分页请求统一用查询参数 `current`、`size`。

### 3. 认证方式

- 登录成功后返回 JWT 令牌，前端存入 localStorage，后续请求在 Header 携带 `Authorization: Bearer <token>`。
- 令牌有效期 30 分钟，闲置超时由后端签发时的 exp 控制。
- 未登录返回 401，权限不足返回 403。

### 4. 时间与金额

- 时间格式：`yyyy-MM-dd HH:mm:ss`，日期格式 `yyyy-MM-dd`。
- 金额单位：元，类型 BigDecimal，保留两位小数。
- 身份证号、银行账号等敏感字段按角色脱敏，脱敏在 Service 层完成。

## 1.1 登录注册模块（对应 M01 用户账号）

### API-001 用户登录

| 项 | 内容 |
|----|------|
| 接口名称 | 用户登录 |
| 请求方式 | POST |
| 接口路径 | `/api/auth/login` |
| 是否需要认证 | 否 |

**入参（JSON Body）**

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| username | String | 是 | 登录账号 |
| password | String | 是 | 登录密码（明文，由 HTTPS 保障） |

**出参 data**

| 字段名 | 类型 | 说明 |
|--------|------|------|
| token | String | JWT 令牌 |
| userId | Long | 当前用户 ID |
| username | String | 登录账号 |
| realName | String | 真实姓名 |
| roleCode | String | 角色编码（ADMIN/HR/EMPLOYEE） |
| roleName | String | 角色名称 |
| menus | Array | 当前用户可访问的菜单树 |

**功能描述**：校验账号密码（BCrypt），账号存在且未停用、未锁定则签发令牌并返回角色与菜单；连续错误 5 次锁定 15 分钟；停用账号拒绝登录。错误统一提示"账号或密码错误"。

# 三、核心业务流程图

## 3.1 用户登录权限校验流程

**流程节点**：
┌──────────────────────┐
│    用户登录流程        │
└──────────────────────┘
1. 用户登录页输入账号密码，点击登录
        │
        ▼
2. 前端组装JSON请求 POST /api/auth/login
        │
        ▼
3. AuthController接收请求、校验入参非空
        │
        ▼
4. LoginService 查询 sys_user 用户表
        │
        ├─ 账号不存在 ── 返回【账号或密码错误】(结束)
        │
        ▼(账号存在)
5. 判断账号状态
        │
        ├─ 账号已停用 ── 返回【账号已停用】(结束)
        │
        ▼(账号正常)
6. 判断锁定状态
        │
        ├─ 账号锁定未解锁 ── 返回【账号已锁定】(结束)
        │
        ▼(未锁定)
7. BCrypt 密码比对校验
        │
        ├─ 密码错误 ── 失败次数+1
        │                ├─ 累计5次→锁定15分钟
        │                └─ 返回【账号或密码错误】(结束)
        │
        ▼(密码正确)
8. 清空失败计数、解除锁定状态
        │
        ▼
9. 权限服务加载角色、权限集合
        │
        ▼
10. 生成JWT令牌(有效期30分钟)
        │
        ▼
11. 审计切面记录登录成功日志
        │
        ▼
12. 返回Token、用户信息、菜单树
        │
        ▼
13. 前端存Token，按角色跳转首页

┌──────────────────────┐
│     异常分支处理       │
└──────────────────────┘
数据库异常 / JWT生成异常
        │
        ▼
全局异常拦截处理
        │
        ▼
返回【登录失败，请稍后重试】，记录ERROR日志，流程终止

### 3.4.3 审批流程（HR）

```
┌──────────────────────┐
│      请假审批流程      │
└──────────────────────┘
1. HR进入请假审批页，切换至【待审批】Tab
        │
        ▼
2. 选中请假单，点击【通过】或【驳回】
        │
        ▼
3. 驳回必须填写驳回原因；通过的审批意见选填
        │
        ▼
4. 调用 PUT /api/leaves/{id}/approve 或 /reject
        │
        ▼
5. LeaveApprovalService 事务处理
        │
        ├─ 校验单据状态为PENDING待审批
        │        ├─ 状态非待审批 ──>提示：单据已处理，终止
        │
        ▼(校验通过)
6. 更新单据状态APPROVED/REJECTED，记录审批人、时间、意见
        │
        ├─ 审批通过 ──> 调用AttendanceService写入对应考勤请假记录
        │
        ▼
7. 审计切面记录本次审批操作日志
        │
        ▼
8. 返回成功，刷新待审批列表
```

**状态机**：
```
提交：(无) ──> 待审批(PENDING)
审批通过：PENDING ──> 已通过(APPROVED) ──> 联动写考勤
审批驳回：PENDING ──> 已驳回(REJECTED)
职工撤销：PENDING ──> 已撤销(CANCELLED)
终态：APPROVED / REJECTED / CANCELLED 不可再变
```

**判断分支汇总**：
```
┌──────────────────────┐
│   请假业务判断分支图    │
└──────────────────────┘
提交
  ↓
时间合法、天数>0、事由非空？ ──否──> 前端提示
  ↓是
保存状态PENDING ──> 提交成功

审批
  ↓
状态=PENDING？ ──否──> 提示单据已被处理
  ↓是
审批通过？──是──> 置APPROVED + 写入考勤(同事务)──>成功
审批驳回？──是──> 置REJECTED(驳回意见必填)──>成功
```

**事务保障**：审批通过时"更新请假单状态 + 写入考勤记录"在同一 `@Transactional` 内，写考勤失败则整体回滚，请假单不更新。
