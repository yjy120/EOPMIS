## 一、测试目的与范围

### 1.1 目的
- 验证 EOPMIS 系统是否满足《PRD》FR-001~FR-022 及非功能性需求
- 暴露功能、性能、安全、易用性、兼容性、数据完整性等方面的缺陷
- 为系统验收与上线提供客观依据

### 1.2 范围内（In-Scope）
| 模块 | 编号 | 主要测试对象 |
|------|------|--------------|
| 用户账号 | M01 | 登录、登出、失败锁定、密码修改、账号-员工绑定 |
| 员工档案 | M02 | 员工主表 + 教育/工作/家庭/附件子表 + 查阅留痕 |
| 部门管理 | M03 | 部门树、CRUD、删除占用校验 |
| 岗位管理 | M04 | 岗位 CRUD、删除占用校验 |
| 劳动合同 | M05 | 登记、续签、终止、到期预警、唯一有效合同 |
| 人事调动 | M06 | 调动发起、生效联动、历史轨迹 |
| 薪资管理 | M07 | 登记、发放确认、修改留痕、本人查询脱敏 |
| 考勤管理 | M08 | 录入、查询、轻量统计、与请假联动 |
| 请假审批 | M09 | 申请、单级审批、通过联动考勤（待评审：若 CR 否决则不测） |
| 权限角色 | M10 | RBAC、行级/字段级权限、脱敏、审计日志、字典 |
| 数据库 | — | 21 张表结构、约束、索引、加密字段、外键应用校验 |
| 接口 | — | API-001~API-054（详细设计约定） |

### 1.3 范围外（Out-of-Scope）
- 多级审批流引擎（PRD 6.2.2 明确本版不引入）
- 工资条/薪酬自动核算、复杂考勤报表
- 与企业微信/钉钉/邮件通知的集成（仅日志落库，不做推送）
- 高并发/海量数据压测（系统目标 1000 人内，常规负载即可）
- 浏览器兼容只验证 Chrome / Edge / Firefox 三家最新 2 个大版本

## 二、测试策略

### 2.1 测试层次
| 层次 | 责任方 | 主要方法 | 准入 |
|------|--------|----------|------|
| 单元测试 | 后端开发 | JUnit 5 + Mockito，DAO 层用 @MybatisTest | 开发自测通过 |
| 接口（集成）测试 | 测试工程师 | Postman / Apifox / Jmeter，重点场景自动化 | 接口联调通过 |
| 系统功能测试 | 测试工程师 | 黑盒手工 + 自动化脚本（Selenium/Pytest） | 集成测试通过 |
| 验收测试 | 指导教师 / 业务代表 | UAT 走查 | 系统测试通过 |

### 2.2 测试类型与占比建议
| 类型 | 占比建议 | 说明 |
|------|----------|------|
| 功能测试 | 60% | 覆盖 FR 的正常路径 |
| **边界 / 异常测试** | **≥20%** | **本初版按 30%~40% 配比**（见 §五） |
| 安全 / 权限 | 10% | 越权、SQL 注入、XSS、敏感字段脱敏、审计 |
| 数据完整性 | 5% | 数据库约束、事务、级联 |
| 性能 / 兼容性 | 5% | 单接口 < 500ms、Chrome/Edge/Firefox 表现一致 |

### 2.3 测试方法
- **黑盒为主**：以 PRD/详细设计的 API 规范为输入，按等价类划分、边界值分析、状态迁移、错误猜测法设计用例
- **白盒为辅**：核心事务（调动生效、续签、请假联动）由开发提供事务回滚用例清单，测试验证

### 2.4 测试原则
- 用例 ID 全局唯一，命名 `TC-<模块编号>-<序号>`
- 每条用例独立可执行（不依赖其他用例的状态，除非在前置中显式声明）
- 缺陷跟踪：使用项目管理系统的 Issue 跟踪，按严重度 P0~P3 分级
- 回归策略：每轮提测后，先回归 P0/P1，再跑全量用例

## 四、进入 / 暂停 / 退出准则

### 4.1 进入准则
- 概要设计、详细设计、数据库设计均已评审通过
- 核心模块（M01/M02/M03/M10）开发完成并提测
- 测试环境就绪、测试数据已初始化
- 用例集（本文档）已评审通过

### 4.2 暂停 / 恢复准则
- **暂停**：发现 P0 阻塞性缺陷 → 暂停该模块测试；提测版本被撤销 → 暂停
- **恢复**：缺陷修复完成、版本重提、回归通过后恢复

### 4.3 退出准则
- 所有 P0、P1 缺陷全部关闭
- P2 缺陷关闭率 ≥ 95%
- 用例通过率 ≥ 98%（30 条用例至多 1 条不通过）
- 覆盖率：FR-001~FR-022 全部覆盖（M09 若 CR 否决则该模块用例标"已跳过"）
- 性能：登录、列表查询、本人薪资查询 P95 < 500ms
- 安全：越权、SQL 注入、XSS 关键路径全部通过
