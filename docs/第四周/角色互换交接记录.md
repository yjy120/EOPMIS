## 4. 项目现状基线（承接原 PROJECT.md）

### 4.1 项目背景

传统企业人事管理多依靠 Excel 表格或纸质档案，存在信息分散、查询困难、人员权限混乱、员工敏感隐私信息缺少保护、人事变更无日志留痕等问题。本系统采用 B/S 架构实现人事信息线上统一管理，配套权限隔离、敏感字段脱敏、操作审计能力。

系统包含三类角色：**系统管理员、人事专员、普通职工**；覆盖部门岗位、职工档案、劳动合同、人事调动、薪资、考勤、账号权限等业务模块。

### 4.2 技术栈（实际采用版本）

| 类别 | 技术 | 版本 |
|------|------|------|
| 后端框架 | Spring Boot + Spring MVC + Spring Security + JWT | 2.7.18 |
| ORM | MyBatis-Plus | 3.5.5 |
| 连接池 | Druid | 1.2.x |
| 数据库 | MySQL | 8.0 |
| JDK | Eclipse Temurin | 17 |
| 前端框架 | Vue 3 + Vite | Vite 5 |
| UI 组件库 | Element Plus | 2.5.6 |
| 状态/路由/请求 | Pinia + Vue Router + Axios | - |

### 4.4 代码约定（沿用基线）

1. Java 代码规范：类名大驼峰；方法名、变量名小驼峰；包名全部小写。
2. 数据库规范：表名、字段名小写加下划线；`sys_` 系统类前缀；主键统一 `id`（BIGINT 自增）。
3. 项目分层：controller → service → mapper → entity，严格单向依赖，Controller 不直接调 Mapper。
4. 安全规范：数据库账号、密钥统一写在 application.yml；后端 `@PreAuthorize` 做权限校验，不依赖前端；密码 BCrypt 不可逆存储。
5. Git 提交规范：提交信息格式 `[AI‑辅助] 简述本次修改内容`。

### 4.5 已完成功能清单（截至第四周）

**基础能力**
- 登录认证（UC-001）：JWT 令牌（30 分钟）、BCrypt 存储、连续失败 5 次锁定 15 分钟、密码历史（不与最近 3 次相同）
- RBAC 权限模型（UC-004）：用户-角色-权限三级，菜单/按钮/接口权限点表驱动，前端动态菜单 + 后端 `@PreAuthorize` 双重校验
- 审计留痕：登录、增删改、密码修改等写入 sys_audit_log，只增不改不删

**系统管理员（ADMIN）**
- 账号管理：分页查询、新增、启用/停用、重置密码
- 角色管理：角色列表、菜单树形授权
- 审计日志查看（仪表盘内嵌）

**人事专员（HR）**
- 部门管理（UC-005）：部门树维护
- 岗位管理（UC-006）：部门下岗位与职级维护
- 职工档案（UC-007/008）：录入、查询、修改、逻辑删除；编号/身份证唯一校验；档案与账号双向绑定
- 劳动合同（UC-010/011）：登记、续签、终止、到期预警
- 人事调动（UC-013）：调动登记、生效回写职工部门/岗位、轨迹留存
- 薪资管理（UC-014）：薪资登记、按月查询
- 考勤管理（UC-015）：考勤录入、查询、轻量统计

**普通职工 / 个人中心（全员）**
- 修改密码（JSR-303 + 密码历史校验）
- 我的档案（UC-009）、我的合同（UC-012）、我的薪资（UC-016）、我的考勤（UC-017）——后端按登录人 employee_id 行级过滤防越权

**首页仪表盘（三角色差异化）**
- ADMIN：统计卡 + 最近审计日志
- HR：6 项统计卡 + ECharts 部门人数柱状图 + 合同到期预警（60 天内，30 天内标红）
- EMPLOYEE：个人统计 + 本月考勤表 + 合同状态卡

**界面美化**：商务蓝主题（登录页渐变、深蓝灰侧边栏、用户胶囊顶栏、统一圆角阴影）
