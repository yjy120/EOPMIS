## 4. 风险与预案（演练中已验证的处置手段）

| 风险 | 触发条件 | 已验证处置 |
|------|---------|-----------|
| 双 MySQL 实例错连（DEF-017） | 新接口 200+code=500、报表不存在 | jdbc URL 固定 `[::1]:3306` 锁 IPv6；用 `Get-NetTCPConnection -LocalPort 3306` 先排端口 |
| JDK 版本不兼容 | 用了 JDK 21/26 启动 Spring Boot 2.7 | 显式 `$env:JAVA_HOME='C:\Program Files\Eclipse Adoptium\jdk-17.0.20.101-hotspot'` |
| node 不在 PATH（DEF-022） | `'node' 不是内部或外部命令` | 命令前注入 `$env:Path = "C:\Program Files\nodejs;$env:Path"`；用 `node node_modules/vite/bin/vite.js` 直启 |
| 中文乱码（DEF-001/007 教训） | PowerShell 管道导入 SQL | 一律带 `--default-character-set=utf8mb4`；应用层 DruidCharsetConfig 兜底 SET NAMES |
| npm install 冷网超时 | 换机/无缓存环境 | 已配 npmmirror 镜像；预案预置 node_modules 或离线 npm 缓存，可压入 30 分钟预算 |
| 端口残留 | 上轮进程未关 | 演练前 Stop-Process 释放 8080/5173 |
| 菜单/权限看起来没生效 | 浏览器旧登录态 | 清 localStorage 重新登录（BLK-006 临时处置，根治待 permVersion） |
