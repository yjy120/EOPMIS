# EOPMIS · 部署说明与环境搭建手册

> 整理日期：2026-09-21
> 适用版本：EOPMIS v0.1.0（工期 2026-08-31 ~ 2026-09-23）

---
## 1. 环境要求

| 软件 | 推荐版本 | 验证命令 |
|------|----------|----------|
| JDK | 17（LTS） | `java -version` |
| Maven | 3.9.x | `mvn -version` |
| Node.js | 18 LTS / 20 LTS | `node -v` |
| npm | 9+（随 Node 18+） | `npm -v` |
| MySQL | 8.0.42+ | `mysql -uroot -p -e "SELECT VERSION()"` |
| PowerShell | 5.1+（Win） | `$PSVersionTable.PSVersion` |
## 2. 端口分配

| 服务 | 端口 |
|------|------|
| 后端 API | 8080（context-path=/api） |
| 前端 Vite dev | 5173 |
| MySQL 8.0 | 3306 IPv6（`[::1]`） |

> **注意**：本机 3306 同时存在 MariaDB（IPv4 socket，zentao 等）和 MySQL 8.0（IPv6 socket）。后端必须用 `[::1]:3306` 强制 IPv6，避免命中 MariaDB（无 `sys_salary` 等表）。

## 3. 数据库准备
### 3.1 创建数据库

```sql
CREATE DATABASE eopmis
    DEFAULT CHARACTER SET utf8mb4
    DEFAULT COLLATE utf8mb4_unicode_ci;
```
### 3.2 执行 schema-rebuild.sql（**仅首次**）

文件位置：`backend/src/main/resources/data-init/schema-rebuild.sql`

```powershell
$env:MYSQL_PWD = "123456"
Set-Location "C:\Program Files\MySQL\MySQL Server 8.0\bin"
.\mysql.exe -h ::1 -uroot --default-character-set=utf8mb4 eopmis -e "source <绝对路径>\schema-rebuild.sql"

# 验证
.\mysql.exe -h ::1 -uroot -e "USE eopmis; SHOW TABLES;"
```
**警告**：
- `schema-rebuild.sql` 含 `DROP TABLE`，**仅首次搭库执行一次**
- `application.yml` 已设 `spring.sql.init.mode=never`，后端启动不会自动重建

## 4. 后端部署
### 4.1 配置

`backend/src/main/resources/application.yml` 关键项（一般无需改动）：

```yaml
spring:
  datasource:
    url: jdbc:mysql://[::1]:3306/eopmis?useSSL=false&useUnicode=true&characterEncoding=UTF-8&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true
    username: root
    password: "123456"
```
### 4.2 构建 + 启动

```powershell
Set-Location "C:\Users\Lenovo\Desktop\EOPMIS\backend"
mvn clean package -DskipTests

# 启动（后台）
Start-Process -FilePath "java" -ArgumentList "-jar", "target\eopmis-backend-0.1.0.jar" `
    -RedirectStandardOutput "logs\app.log" `
    -RedirectStandardError "logs\app.log.err" `
    -WindowStyle Hidden

# 验证
Get-NetTCPConnection -LocalPort 8080 -State Listen
```
启动成功标志：日志出现 `Started EopmisApplication in X.XXX seconds`。

## 5. 前端部署
### 5.1 安装依赖

```powershell
$env:Path = "C:\Program Files\nodejs;$env:Path"
Set-Location "C:\Users\Lenovo\Desktop\EOPMIS\frontend"
npm config set registry https://registry.npmmirror.com   # 国内镜像可选
npm install
```
### 5.2 启动

```powershell
# 启动（后台）
Start-Process -FilePath "C:\Program Files\nodejs\npm.cmd" `
    -ArgumentList "run", "dev" `
    -WorkingDirectory (Get-Location) `
    -RedirectStandardOutput "logs\vite.log" `
    -RedirectStandardError "logs\vite.err" `
    -WindowStyle Hidden

# 验证
Get-NetTCPConnection -LocalPort 5173 -State Listen
```

## 6. 启动验证
### 6.1 全栈启动顺序

1. MySQL 8.0 服务已启动
2. 后端：`java -jar target\eopmis-backend-0.1.0.jar`
3. 前端：`npm run dev`
