### 2.5 专项验证

- **权限安全**：未登录 401、跨角色访问 403、IDOR 越权（篡改 id 参数）全部拦截；SQL 注入用例（部门名/员工名/合同号/薪资月份/考勤日期 5 组）参数化查询均未注入。
- **字符集**：4 天持续做 hex 级验证，所有中文表（部门/岗位/职工/菜单/合同/调动/薪资/考勤）UTF-8 字节正确，浏览器渲染无乱码。
- **事务一致性**：合同续签（原合同置到期+新合同插入）、调动生效（sys_employee 部门岗位回写）均验证 `@Transactional` 回滚正确。
- **第四周回归**：三角色菜单权限边界、11 个账号独立登录、商务蓝美化后三角色仪表盘（含 ECharts 柱状图）全部实测通过；`mvn compile` 退出码 0。

### 4.2 已知架构债务与技术风险

| 编号 | 事项 | 风险等级 | 说明与建议 |
|------|------|---------|-----------|
| BLK-006 / DEF-011 | userStore 权限缓存无版本机制 | 中 | 权限变更后需手动清 localStorage 重登录；建议 LoginResp 增 `permVersion`，前端比对自动失效 |
| BLK-007 | 双 MySQL 实例共存（MariaDB IPv4 / MySQL 8.0 IPv6 同占 3306） | 中 | 现靠 jdbc URL 锁 `[::1]` 绕过；换机/重装环境易复发，部署手册已显著标注，长期应停 MariaDB 或改 3307 |
| BLK-008/009 | 10 万级数据量、并发插入未测 | 低 | 课设规模（11 职工）无性能瓶颈；正式上线前补压测与并发测试 |
| BLK-003/004 | emp_no+idCard 联合唯一索引、合同号业务规则 | 低 | 当前应用层校验已覆盖主路径；建议补数据库联合索引兜底 |
| 需求缺口 | M09 请假审批模块未开发 | 中 | PRD 已通过需求变更保留，本期范围外；答辩演示不涉及 |
| 数据一致性 | 合同静态 status 与 end_date 动态计算口径不一致 | 低 | 可能出现"已到期但状态有效"；待决策 HR 手动维护或后端定时刷新 |
| 安全基线 | 身份证/银行账号加密存储与差异化脱敏、30 分钟会话闲置失效未完全落地 | 中 | 设计基线要求，生产化前必须补齐（TypeHandler 加密 + 注解脱敏 + 会话超时） |
| 演示配置 | `force-reset-on-startup=true` | 中（仅演示环境） | 每次启动重置种子密码；**上生产必须置 false**，部署手册已警示 |
