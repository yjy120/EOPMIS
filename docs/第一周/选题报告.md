# 选题报告

## 一、题目名称

企业职工人事在线管理信息系统的设计与实现

## 二、复杂工程问题描述

在系统管理员、人事专员、普通职工三类角色共用同一套人事业务数据开展工作的场景下，如何实现职责分离的细粒度权限管控、职工敏感信息字段脱敏、人事业务变更全链路审计留痕三位一体的数据安全治理方案。 本系统需要隔离不同角色的数据访问范围，对身份证、薪资等敏感字段脱敏，所有人事档案修改、调动操作留存审计日志，在保障人事业务正常办理的前提下，满足企业人事数据安全合规的要求。

## 四、项目简介

本系统为 B/S 架构企业人事在线管理系统，面向企业内部人员，实现部门管理、职工档案管理、劳动合同、人事调动、考勤、基础权限管理功能。本版本不实现薪资自动核算、人脸识别打卡、第三方系统对接等功能。
