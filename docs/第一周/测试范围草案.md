## 一、文档目的

本草案作为本项目测试活动的起点，用于明确：

1\. 本次测试**测什么**（测试对象）；

2\. 本次测试**怎么测**（测试方法）；

3\. 本次测试**什么时候开始、什么时候结束**（准入 / 准出条件）。  
供项目经理、开发负责人、测试组评审对齐后形成正式《测试计划》。

## 三、测试方法

### 3.1 测试类型与方式

| **测试类型**   | **测试方法**                                    | **适用对象**         | **工具 / 手段**                                 |
| -------------- | ----------------------------------------------- | -------------------- | ----------------------------------------------- |
| **功能测试**   | 黑盒手工测试 + 等价类划分 + 边界值分析 + 判定表 | T-01 ~ T-10          | 用例设计参照 PRD 第七章用例描述 UC-001 ~ UC-017 |
| **权限测试**   | 基于角色的正向 / 反向用例                       | T-01、T-02、T-11     | 三种角色账号交叉操作、URL 直访越权尝试          |
| **接口测试**   | 自动化接口测试                                  | T-01 ~ T-09 后端 API | Postman / Apifox / JUnit + RestAssured          |
| **安全测试**   | 手工渗透 + 自动化扫描                           | T-11、PRD 5.1 节     | 越权访问、SQL 注入、XSS、密码加密、登录锁定     |
| **性能测试**   | 负载 / 压力测试                                 | T-12                 | JMeter / Locust，参照 PRD 5.2 节指标            |
| **兼容性测试** | 多浏览器交叉验证                                | PRD 5.3.6、6.1.4     | Chrome 90+ / Edge 90+ / Firefox 88+             |
| **易用性测试** | 任务走查 + 评分表                               | PRD 5.3 节           | 测试人员实际操作 + 用户体验评分                 |
| **可靠性测试** | 异常注入 + 事务回滚验证                         | PRD 5.5 节           | 模拟断网、数据库连接失败、并发操作              |
| **回归测试**   | 自动化回归 + 手工冒烟                           | 全部                 | 每次发版前执行                                  |

### 3.2 测试层次

| **层次** | **实施阶段**   | **出口标准**                   |
| -------- | -------------- | ------------------------------ |
| 单元测试 | 开发联调阶段   | 关键业务方法覆盖率 ≥ 70%       |
| 集成测试 | 功能开发完成后 | 各模块接口互通、数据库读写正常 |
| 系统测试 | 集成测试通过后 | 本草案 P0 全部用例通过         |
| 验收测试 | 系统测试通过后 | 业务方签字                     |

### 3.3 测试重点（基于 PRD 业务风险最高项）

1\. **三类角色权限严格隔离**：依据 PRD 2.3 权限矩阵——系统管理员严禁触达业务数据；人事专员严禁操作账号权限；普通职工严禁越权查看他人数据。

2\. **"本人数据"过滤**：依据 PRD 5.1.2 与 5.1.5，URL 直接传他人 ID 也必须被后端拦截。

3\. **人事调动的级联更新**：依据 PRD FR-015，调动生效后职工档案中的部门 / 岗位必须同步更新，且保留历史轨迹。

4\. **合同到期提醒**：依据 PRD FR-012，距到期 30 天内在列表中醒目提示。

5\. **薪资记录不可篡改**：依据 PRD FR-017，发放确认后原则上不可修改，特殊情况需记录原因。

6\. **登录失败锁定**：依据 PRD 5.1.3，连续 5 次密码错误锁定账号 15 分钟。
