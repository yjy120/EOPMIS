# 企业职工人事在线管理信息系统(EOPMIS)
Enterprise Online Employee HR Management Information System
生产实习 Vibe‑Coding 三人小组项目

## 介绍
随着企业规模扩大，企业内部职工数量增多，人员流动频繁。传统人事管理依赖Excel表格、纸质档案进行管理，存在数据分散、查询统计效率低、档案容易丢失，权限管控混乱等现实问题。HR人员大量时间消耗在档案整理、合同到期提醒、薪资考勤统计等重复工作；普通职工无法自助查看个人档案、合同、薪资考勤信息。

本系统采用B/S架构，开发一套人事综合管理平台，覆盖部门岗位、职工档案、劳动合同、人事调动、薪资、考勤、账号权限全套业务。
系统划分三类用户角色：**系统管理员、人事专员、普通职工**。实现细粒度权限隔离，对身份证、薪资等敏感信息脱敏，人事变更全部操作留痕审计，满足个人信息保护的合规要求。

- **后端**：SpringBoot + SpringMVC + MyBatis，JDK11
- **前端**：Vue3 + Element‑Plus
- **数据库**：MySQL 8.0
- **项目分层**：controller控制层、service业务层、mapper数据访问层、entity实体层、config配置层

## Git分支策略
- `master`：主分支，存放稳定版本。**禁止直接在此分支修改提交**，仅接受来自dev分支的合并请求。
- `dev`：开发分支，小组全部文档、代码开发均在此分支完成。

## 安装教程（后续骨架完成后使用，当前为初始化阶段）
1. 后端：进入`backend`目录，修改`application-dev.yml`数据库连接配置；运行`EopmisApplication`启动类。
2. 前端：进入`frontend`目录，执行 `npm install`，执行 `npm run dev`。

## 使用说明
1. 系统管理员：负责账号创建、角色权限分配，不处理人事业务数据。
2. 人事专员：维护部门、职工档案、合同、调动、薪资考勤全部业务。
3. 普通职工：仅可查看本人档案、合同、薪资考勤，仅允许修改自身登录密码。

## 参与贡献（小组内部协作规则）
1. 所有工作在 `dev` 分支开展。
2. 修改文档/代码前，先拉取远程最新内容，避免冲突。
3. 提交信息写明本次改动内容。
4. 功能全部完成测试后，在Gitee网页提交Pull Request，将dev合并至master。
